# ساخت APK برای Valy Launcher

بعد از ساخت، اپ با آیکون خودش توی منوی گوشی نصب می‌شه، آفلاین کار می‌کنه و هیچ آدرسی لازم نداره.

## راه ۱: ساخت خودکار با GitHub (بدون نصب هیچ ابزاری)
1. روی کامپیوتر وارد github.com شو و یک ریپوی جدید (خصوصی یا عمومی) بساز.
2. زیپ رو استخراج کن. **همه‌ی محتوای پوشه** (از جمله پوشه‌ی مخفی `.github`) رو با Add file ← Upload files داخل ریپو بکشون و Commit کن.
3. تب **Actions** ← صبر کن workflow سبز بشه (حدود ۳ تا ۵ دقیقه).
4. از بخش **Releases** (سمت راست صفحه‌ی ریپو) فایل `ValyLauncher.apk` رو دانلود کن.
5. APK رو به گوشی بفرست (تلگرام، کابل، ...) و نصبش کن. اگه خواست، اجازه‌ی «Install unknown apps» رو بده.

## راه ۲: ساخت با Android Studio
پوشه رو باز کن ← Build ← Build APK(s). فایل خروجی توی `app/build/outputs/apk/release` هست.

## نکته‌ها
- فایل `valy.jks` کلید امضای اپه. نگهش دار تا نسخه‌های بعدی روی نسخه‌ی قبلی نصب بشن و اطلاعاتت پاک نشه.
- اگه اپ رو آپدیت کردی، بازم از Settings ← Data ← Export all بک‌آپ بگیر.
- فایل‌های اپ توی `app/src/main/assets` هستن. برای نسخه‌ی جدید، `index.html` رو اون‌جا جایگزین کن و دوباره بساز.
- اگه ظاهر اپ بهم‌ریخته بود، Android System WebView رو از فروشگاه آپدیت کن.
